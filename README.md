# BreadGit distribution

Public HTTPS distribution metadata and future Windows release downloads for BreadGit.

- Status: https://breadpack.github.io/breadgit-releases/stable/status.json
- Downloads: https://breadpack.github.io/breadgit-releases/

Stable activation is pending public Windows code signing and signed-release acceptance. No installer is published here yet. This repository does not mirror application source or contain private signing keys.

Metadata public keys are informational; the application trusts its compiled roots rather than downloading new trust roots from this website.
