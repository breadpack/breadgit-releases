# BreadGit distribution

BreadGit 0.1.0 is available as an **unsigned manual-install prerelease**. Automatic updates and the signed stable channel remain disabled.

- Download: https://breadpack.github.io/breadgit-releases/
- Prerelease: https://github.com/breadpack/breadgit-releases/releases/tag/v0.1.0-manual-unsigned
- Stable/manual status: https://breadpack.github.io/breadgit-releases/stable/status.json

Windows 11 24H2+ x64. No test certificate installation is required. Windows or organization policy may warn or block this unsigned installer. The first publicly signed version requires a manual replacement install.

This repository does not mirror application source or contain private signing keys. Metadata public keys are informational; the application trusts compiled roots rather than downloading new trust roots from this site.
